# Project Proof of Work Assets Guide

Drop your real Power BI screenshots, data models, and PDF project reports into their respective folders:

### 1. `assets/projects/cyber-threat/`
- `dashboard.png` (or `.jpg` / `.svg`): Power BI Cyber Threat Intelligence Dashboard screenshot
- `datamodel.png` (or `.svg`): Star Schema Data Model diagram
- `report.pdf`: Cyber Threat Project Report / Executive Summary PDF

### 2. `assets/projects/upi-fraud/`
- `dashboard.png`: UPI Fraud Analytics Power BI Dashboard screenshot
- `report.pdf`: UPI Fraud Analytics Project Report PDF

### 3. `assets/projects/black-friday/`
- `dashboard.png`: Black Friday & RFM Segmentation Dashboard screenshot
- `report.pdf`: Black Friday RFM Customer Segmentation Report PDF

### 4. `assets/projects/shopease/`
- `dashboard.png`: ShopEase E-Commerce Business Intelligence Dashboard screenshot
- `report.pdf`: ShopEase BI Case Study Report PDF

> **Note**: The portfolio automatically detects and displays your screenshots and enables 1-click viewing/downloading of your PDF reports.
